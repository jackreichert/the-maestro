# Recovery plugin

Load with [Retro](../SKILL.md) when selected. Goal: recover the right work and knowledge cheaply, without missing commitments or stealing ownership.

- Sample a recent topic and interrupted task using fresh minimal context. Check correct priority/task, rationale, ruled-out options, correction newer than the brief, next action, permissions, ownership, and relevant library sources. Measure context size, retrieval steps/time, accuracy, and gaps.
- Audit failed/pending writes, duplicate IDs, invalid records/references, coverage watermarks, contradictions, unresolved answered questions, stale library sources, and broken shared-document pointers. Separate missing capture from projection/index failure; never silently skip corrupt records.
- Check approved backups cover source ledger, topic metadata, vault pages, pending operations, and plugin records; indexes are rebuildable, not backups. Verify a bounded restore/rebuild in an isolated approved location. No secret-bearing copies, production overwrite, automatic Git commits, or history deletion.
- Set baseline/sample, accuracy floor, recovery budget, sustained observation period, and reopening threshold in the registry. Report untested restore/coverage explicitly; propose focused repairs rather than full-library rewrites.
